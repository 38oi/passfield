# Еще один локальный менеджер паролей с заметками и шифрованием

Шифруется все локальным ed25519 ключом, должен лежать в %USERPROFILE%/.ssh/id_ed25519.
Все, что пишется - в локальный файл SQLite базы данных, в уже зашифрованном виде. Заметки так же шифруются.

Основной интерфейс на библиотеке D3, бесконечный canvas с карточками. Поддерживаются связи между паролями, взаимосвязанные пароли попадают в предложенные. Поиск - сквозной по всем вхождениям, и по заметкам, и по паролям.

Запуск:
```python
python -m run.py
```

Предполагается, что этот проект - заготовка, транспорт ключей и БД вы организуете удобным вам способом.
